Open Source05 / 11Von K.A. zu K.I.

KI-⁠Begriffe, sauber erklärt und durch die Brille der eigenen Branche gesehen.

Jeder Begriff hat eine fachliche Definition und daneben mehrere Erklärwelten, etwa Automotive, Public Sector, Healthcare und Finance & Banking.

Was
Analogiebasiertes KI-Glossar mit Suche, Filtern und Lernpfaden
Für wen
Menschen, die mit KI arbeiten, aber keine KI-Fachleute sind
Womit gebaut
Astro, TypeScript, Fuse.js, GitHub Pages
Stand
Live, Code unter MIT-Lizenz

Ein Begriff, mehrere Brillen

Zu jedem Begriff gehören Definition, warum er wichtig ist, typische Missverständnisse und mehrere Perspektiven. Jede Analogie nennt auch ihre Grenze, denn jede Brille zeigt eine Seite und verschweigt eine andere.

Wo man einsteigt

Man kann das Glossar per Volltextsuche durchsuchen, die Perspektive wechseln oder einem Lernpfad für Management, IT oder Einsteiger folgen. Dazu gibt es kleine Wissenstests.

Ohne Server

Die Seite ist komplett statisch. Die Suche läuft im Browser über eine JSON-Datei, es gibt keine Server-Komponente und keine externen KI-Dienste.
