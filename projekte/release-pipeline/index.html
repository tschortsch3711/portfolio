Musik08 / 11Release-Pipeline

Claude Code bringt die Songs auf Spotify, aber nur nach Freigabe.

Ein Claude-Code-Projekt mit neun Skills und 21 Skripten. Es bedient Suno, ChatGPT, Amuse und Musixmatch im Browser. Generiert, heruntergeladen und abgeschickt wird nur nach ausdrücklicher Freigabe.

Was
Release-Pipeline für die Songs von tschortsch
Für wen
Für den eigenen Gebrauch, oft per Sprache vom iPhone aus
Womit gebaut
Claude Code, Claude in Chrome, Python und JavaScript
Stand
In Gebrauch seit September 2026, Repo privat

Jeder Schritt ein Skill

Neuer Song, Generieren, Import, Download, Cover, Cover bereinigen, Analyse, Release und Lyrics nachreichen sind eigene Skills. Zu jedem Song gibt es eine song.json, die den Stand vom Entwurf bis zur Veröffentlichung festhält.

Freigabe statt Autopilot

Bei Suno wird erst nach einem ausdrücklichen „Los“ generiert und nur auf Anweisung heruntergeladen. Bei Amuse geht nichts raus, bevor eine vollständige Zusammenfassung gezeigt wurde und ein „Go“ kam. Captchas löst der Mensch selbst.

Skript vor Klick

Im Browser arbeitet Claude möglichst per Skript über Beschriftungen und Formularfelder statt über Klicks auf Koordinaten. Jeder neu gefundene Weg wandert als Helfer in die Skripte und in den passenden Skill.

Nach dem Release

Spotify zeigt Lyrics nur über Musixmatch. Die Pipeline holt den gesungenen Text aus Suno, prüft ihn und reicht ihn ein, zeitsynchron anhand der Zeitstempel aus Suno.
