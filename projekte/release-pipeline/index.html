Kunst & Musik08 / 11Release-Pipeline

Aus gemeinsamen Erlebnissen werden Erinnerungen, die man hören kann.

Ein Fotoalbum schlägt man selten auf. Ein Song läuft einfach mit: im Auto, beim Kochen und in der Playlist der Freunde, die dabei waren.

Was
Release-⁠Pipeline für die Songs von tschortsch
Für wen
Für den eigenen Gebrauch
Womit gebaut
Agentische KI im Browser, Python und JavaScript
Stand
In Gebrauch seit September 2026, Repo privat

Jeder Schritt ein Skill

Neuer Song, Generieren, Import, Download, Cover, Cover bereinigen, Analyse, Release und Lyrics nachreichen. Eine Statusdatei pro Song hält fest, wie weit er vom Entwurf bis zur Veröffentlichung ist.

Freigabe statt Autopilot

Generiert, heruntergeladen und veröffentlicht wird erst nach ausdrücklicher Freigabe. Vor jedem Release steht eine vollständige Zusammenfassung zum Gegenlesen.

Nach dem Release

Spotify zeigt Lyrics nur über Musixmatch. Die Pipeline holt den gesungenen Text aus Suno, prüft ihn und reicht ihn ein, zeitsynchron anhand der Zeitstempel aus Suno.
