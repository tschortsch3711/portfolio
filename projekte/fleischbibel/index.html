Open Source05 / 08Fleischbibel

Alles, was in der Gruppe zu wichtig ist, um im Chat unterzugehen.

Regeln, Termine, Rituale und Begriffe der Fleischgemeinschaft an einem Ort, statt verstreut in Gruppenbeschreibung und Chatverlauf.

Was
Dokumentation einer WhatsApp-Gruppe
Für wen
Die Fleischgemeinschaft, besonders Neue
Womit gebaut
VitePress, Markdown, GitHub Actions
Stand
Live, Code unter MIT-Lizenz

Wofür es sie gibt

WhatsApp ist für schnelle Abstimmung. Die Fleischbibel erklärt dauerhaft Regeln, Abläufe und Grundsätze. Wer neu ist, fängt mit dem 2-Minuten-Guide an.

Was drinsteht

Die Gemeinschaft selbst, Regeln für Chat und Treffen, die Organisation ohne Oberhaupt, das Fleischmeldeamt mit der monatlichen Verfügbarkeitsabfrage und die Kultur mit Begriffen, Hymne und Chronik.

Wie sie gepflegt wird

Alle Seiten sind Markdown-Dateien. Nach einem Push auf main baut GitHub Actions die Seite und veröffentlicht sie.
